# Формат сценария

Сценарий — граф узлов в JSON. Хранится в таблице `scenarios.graph` (JSONB).

```json
{
  "start_node": "n1",
  "nodes": {
    "n1": {
      "text": "Пассажир в вагоне 3 громко конфликтует с соседом из-за откинутого кресла.",
      "timer_seconds": 20,
      "timeout": {
        "effects": {"loyalty": -10, "safety": -5},
        "next_node": "n2_escalation"
      },
      "choices": [
        {
          "id": "c1",
          "text": "Вежливо предложить пассажирам компромисс по креслу.",
          "effects": {"loyalty": 5, "safety": 0},
          "next_node": "n2_resolved"
        },
        {
          "id": "c2",
          "text": "Попросить пассажира прекратить конфликт в приказном тоне.",
          "effects": {"loyalty": -5, "safety": 5},
          "next_node": "n2_tense"
        }
      ]
    },
    "n2_resolved": {
      "text": "Конфликт исчерпан, пассажиры довольны.",
      "is_ending": true,
      "ending_summary": "Клиентоориентированное решение конфликта."
    },
    "n2_escalation": {
      "text": "Конфликт перерос в потасовку. Требуется вызов охраны.",
      "is_ending": true,
      "ending_summary": "Ситуация вышла из-под контроля из-за промедления."
    },
    "n2_tense": {
      "text": "Пассажир затих, но написал жалобу.",
      "is_ending": true,
      "ending_summary": "Безопасность соблюдена, лояльность пассажира снижена."
    }
  }
}
```

## Правила

- `start_node` — id узла, с которого начинается попытка (`Attempt`).
- Узел без `is_ending: true` обязан иметь `choices` (1+) и `timer_seconds`.
- `timeout` — обязателен для не-финальных узлов: что происходит, если игрок не успел выбрать.
- `effects.loyalty` / `effects.safety` — целые числа (могут быть отрицательными), прибавляются к текущим шкалам попытки. Шкалы ограничены диапазоном [0, 100], клампятся на бэкенде.
- `next_node` должен существовать в `nodes`.
- `condition` (опционально, на выбор) — простое выражение вида `{"min_safety": 40}` / `{"min_loyalty": 40}`: выбор показывается/принимается только если условие выполнено. В MVP-срезе не обязателен, но формат уже поддерживается для будущих сценариев.
- Финальный узел (`is_ending: true`) не содержит `choices`, содержит `ending_summary` — текст для экрана обратной связи.

Валидация графа выполняется при создании/обновлении сценария (`app/scenarios/validator.py`): все `next_node` существуют, `start_node` существует, у не-финальных узлов есть `choices` и `timeout`.
