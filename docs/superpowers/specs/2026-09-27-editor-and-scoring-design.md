# Редактор и очки: дизайн (27.09.2026)

Согласовано с командой в чате. Цель — расширить редактор и геймификацию перед сдачей.

## 1. Очки: идеальное прохождение = 100
- Сырой результат — как раньше: `(лояльность + безопасность + 1) // 2`; шкалы остаются 0–100.
- `score_range(graph)` обходит все достижимые состояния (узел, шкалы, флаги), включая тайм-ауты,
  и возвращает худший и лучший сырой результат среди финалов. Без рекурсии, циклы допустимы.
- Итог: `round(100 × (сырой − худший) / (лучший − худший))`; если лучший = худший — 100.
- Больше 200 000 состояний — ошибка валидатора «сценарий слишком разветвлён».
- Опыт = сумма лучших результатов по сценариям (максимум 100 за сценарий).
- Миграция 0010 пересчитывает `attempts.score` и `scenario_best` по снимкам графов.

## 2. Свои достижения в сценарии
- `graph.achievements: [{id, title, description, icon, when}]`, icon ∈ medal/star/shield/heart/handshake/clock.
- Выдаются на финальном состоянии; хранятся как `s:<scenario_id>:<id>`, название/описание/значок копируются
  в `employee_achievements` (новые колонки, `achievement_id` до 120 символов).
- Профиль: встроенные + свои из опубликованных сценариев (полученные и нет). Редактор: блок «Достижения».

## 3. Свой финал
- В финале `outcome: "custom"`, `outcome_label` (текст), `outcome_tone` (good/neutral/bad).
- API результата отдаёт label и tone; редактор — вариант «Свой…».

## 4. Автовысота текстовых полей — компонент `AutoTextarea` для всех полей редактора.

## 5. Сцена
- Фигуры: + elderly, child, chief, medic, conductor, business. Поля персонажа: `gender` (m/f/n), `color`.
- Позы: sitting, standing, unwell, pointing, hands_on_hips. Позиции: far_left, left, center, right, far_right.
- Узел: `visual.cast: [{character, pose?, position?, when?}]` — если задан, в кадре только они.
- Предметы: + first_aid_kit, water, phone, stroller, bag. Фон: `visual.background` standard/business/vestibule
  (граф и узел).
- «Пассажиру стало плохо» использует новые возможности.

## Проверка
Тесты бэкенда (обход, нормализация, достижения, финал, сцена, миграция), фронтенд-тесты graphOps,
прогон в браузере, обновление scoring.md и scenario-format.md.
